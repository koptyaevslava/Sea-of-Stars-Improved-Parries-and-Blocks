# Changelog

## 2.2.4

- Added bounded hold assistance for blocks and timed bonus attacks.
- Added combo-gated extended hold assistance for repeating timed-input special attacks.
- Added coverage for Moonrang, Soonrang, Limbo, Arcane Barrage, Resh'an's multi-flask attack, Venom Flurry, Leap Frog, Trapeze, and Jugglenaut.
- Added a native-styled, localized Mods tab in the Options screen.
- Added a threshold-capped battle counter with continuous gold pulse feedback.
- Added a standalone installer with package validation, rollback, verification, and removal.
- Added a Nexus-safe manual-install package without executables or nested archives.
